# План ускорения загрузки товаров

## Проблема
Товары загружаются ~5 секунд. `products.json` больше не используется как fallback, поэтому нужна альтернативная стратегия быстрой загрузки.

## Текущая архитектура
- **Источник истины**: Supabase (`products` таблица)
- **Клиент**: `@tanstack/react-query` с кэшированием 2 минуты
- **Проблемы задержки**:
  1. Supabase запрос на холодном кэше (~1-3с)
  2. Отсутствие индикатора прогресса при загрузке
  3. Нет prefetching при навигации по разделам

## Предлагаемые решения

### 1. Оптимизация Supabase запроса
- Добавить селективные индексы в Supabase на `priority` и `category`
- Использовать `count: 'exact'` только где нужно, не в основном запросе
- Уменьшить `staleTime` до 30с для более быстрого отображения изменений админа
- Добавить `retry: 1` и `retryDelay: 1000` для быстрого повтора при сетевых ошибках

### 2. Skeleton loading + оптимистичный UI
- Показывать skeleton-карточки вместо спinnера на 1-2 секунды
- Кэшировать последний успешный ответ в `sessionStorage`
- При повторном посещении показывать кэш мгновенно, а обновлять в фоне

### 3. Prefetching на Section-переходах
- При скролле к разделу "Каталог" (`IntersectionObserver`) запускать фоновый prefetch
- Prefetch категорий по наведению на таб (desktop)
- Mobile: prefetch при появлении bottom-nav

### 4. Edge Caching / CDN
- Развернуть Supabase Edge Function для экспорта товаров в статический JSON
- Обновлять JSON при каждом изменении через webhook
- Раздавать через CDN (Vercel Edge / Cloudflare) с TTL 60с
- Клиент может параллельно запрашивать статику и Supabase, используя то что пришло быстрее (race condition pattern)

### 5. Web Worker для парсинга
- Вынести сортировку и фильтрацию товаров в Web Worker
- Это убережет главный поток при переключении категорий

### 6. Оптимизация изображений
- Использовать `loading="lazy"` + ` decoding="async"`
- Добавить placeholder blur-up через маленькие base64 превью
- Предзагружать изображения только для первого экрана

## Приоритетная дорожная карта

| Этап | Действие | Эффект |
|------|----------|--------|
| 1 | sessionStorage кэш + skeleton UI | Мгновенный показ при повторном визите |
| 2 | Оптимизация запроса + retry | Снижение задержки на 30-50% |
| 3 | Prefetch на скролле | Каталог готов к моменту скролла |
| 4 | CDN fallback | Стабильная загрузка < 500мс |
| 5 | Web Worker | Плавность UI при фильтрации |

## Заметки
- `products.json` оставляем в репозитории как эталон, но НЕ импортируем в код
- Админка продолжает работать через Supabase
- При миграции на CDN нужно сохранить совместимость с `products-updated` событием
